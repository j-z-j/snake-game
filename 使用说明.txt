一、直接玩：不需要安装任何环境
--------------------------------------------------
1. 先把整个 zip 解压到一个文件夹，不要在压缩包里直接双击。
2. 双击根目录的“打开真彩色版.bat”，或双击：
   snake_gui\snake_gui.exe
3. 想玩控制台版：双击“打开控制台版.bat”，或：
   snake_hd\snake_hd.exe

不需要安装 Python、Code::Blocks、MinGW、.NET 运行库。
两个 exe 都已静态链接，只依赖 Windows 自带的 DLL（KERNEL32 / USER32 / GDI32 / gdiplus / msvcrt / WINMM）。
推荐 Windows 10 / 11 64 位；Windows 7 64 位一般也能运行。

二、第一次运行被系统拦截怎么办
--------------------------------------------------
- Windows SmartScreen：点“更多信息” → “仍要运行”。
- 提示压缩包来自网络：右键 zip → 属性 → 勾选“解除锁定” → 确定，再解压。
- 杀毒软件误报 .bat：可以跳过 bat，直接运行 snake_gui\snake_gui.exe。
- 如果 exe 被单独复制出来会缺少 emoji/音效，必须保留整个 snake_gui 文件夹。

三、操作
--------------------------------------------------
方向键 / WASD   移动
空格 / P        暂停 / 继续
F3 / F4         加速 / 减速（1–5 档，默认 3 档）
M               背景音乐开关
Esc             游戏中返回菜单；菜单中退出
Enter / 空格    菜单开始；结算界面再来一局
R               结算界面重开
Q               菜单退出

按键后蛇头会立即转向，身体在下一个逻辑步移动（默认 3 档 155ms/步）。
如果觉得慢，按 F3 升到 4/5 档。

五、源码 / 编译（可选）
--------------------------------------------------
- 控制台版：打开 snake_hd\snake_hd.cbp，或运行 snake_hd\build.bat。
- GDI+ 版：打开 snake_gui\snake_gui.cbp，或运行 snake_gui\build_gui.bat。
需要 Code::Blocks + MinGW-w64；玩家不需要这些。
原版源码\ 里的 tcs.cbp 缺少 map.c / mywindows.c，且没有链接 winmm，
不能直接构建，仅作对照；原因见“代码审查与优化报告.md”。
